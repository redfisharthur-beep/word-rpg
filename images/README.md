# Word RPG 圖像資產

所有正式圖檔都直接放在這個 `images/` 資料夾內，不再分類子資料夾。

## 共通規格

- PNG 透明背景
- 建議 1024 × 1024 原圖
- 莫蘭迪低飽和色系
- 線條乾淨、輪廓清楚
- 手機小尺寸仍可辨識
- 圖內不要放文字

- `warrior.png` — 戰士
- `mage.png` — 法師
- `archer.png` — 弓手
